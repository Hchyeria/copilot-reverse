`/setup-pi` configures the pi coding agent: pick your Copilot models from a checklist and copilot-reverse writes them into `~/.pi/agent/models.json` as two custom providers — `copilot-reverse-anthropic` (Anthropic Messages) and `copilot-reverse-openai` (OpenAI Chat Completions) — so any model can be run over either translation path. Each entry carries its real context window, output cap, image support, and reasoning levels (clamped to the efforts the model actually accepts). `/reset-pi` removes them again, leaving the rest of your pi config untouched. pi now shows up as a third client in the status card, `/config`, and the web dashboard.
